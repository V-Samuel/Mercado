# Documentação do Sistema AEMEK - Fases 1 a 3 concluídas

Este documento registra todo o desenvolvimento e as funcionalidades já entregues no ecossistema AEMEK até o presente momento. O sistema foi dividido em fases para garantir escalabilidade, segurança e estética premium.

## 1. Fase 1: API e Banco de Dados (Laravel 11)
Toda a infraestrutura lógica central foi construída no diretório `/backend`.

*   **Banco de Dados (`aemek`)**: Modelagem completa através de *Migrations*.
    *   `users`: Usuários do sistema (com controle de `nivel_acesso`).
    *   `categorias`: Organização de departamentos.
    *   `produtos`: Cadastro do item contendo `sku` (código de barras), preços de custo/venda e controles de `estoque_atual` e `estoque_minimo`.
    *   `movimentacoes`: Tabela de auditoria para rastrear todas as entradas e saídas.
*   **Segurança e Autenticação**: 
    *   Implementação do **Laravel Sanctum** para emissão de tokens seguros (JWT).
    *   A API protege as rotas de estoque para que apenas usuários logados (com um *Bearer Token* válido) possam consultá-las.
    *   Senha com hash forte (Bcrypt).
*   **Regra de Negócio Central**:
    *   O `MovimentacaoController` foi blindado com **Transações de Banco de Dados (`DB::beginTransaction`)**.
    *   Se um operador tentar realizar a saída de um produto com quantidade maior que o estoque atual, a API recusa a transação retornando erro `400` ("Estoque insuficiente").
*   **Dashboard API**:
    *   Foi criado um controlador específico para alimentar o front-end, retornando a soma de movimentações do dia e varrendo o banco de dados atrás de produtos cujo `estoque_atual` <= `estoque_minimo`.

## 2. Fase 2: Painel Administrativo Web (React + Vite)
O painel de controle gerencial (lojista) foi construído no diretório `/painel`, utilizando **React** e o novíssimo **TailwindCSS v4**, com foco total em "Flat Design" de alta velocidade e mínimo de cliques.

*   **Sistema de Login Seguro**:
    *   Tela de entrada sofisticada. Captura o token via Axios e o salva no `localStorage`, redirecionando para a área logada.
*   **Layout Componentizado**:
    *   Sidebar e Header fixos. O nome e cargo do usuário logado são renderizados dinamicamente na barra superior.
*   **Dashboard Operacional**:
    *   Visualização rápida (em tempo real) de "Total de Produtos", "Entradas Hoje" e "Saídas Hoje".
    *   Tabela dinâmica de "Atenção: Estoque Baixo", priorizando itens que necessitam de reposição imediata.
*   **Módulo de Produtos (O Core do Painel)**:
    *   Tabela principal exibindo todo o catálogo, variação de preços e status de estoque com indicativos de cor.
    *   **Modal de Categorias**: Cadastro rápido de novos grupos (sem precisar sair da tela de produtos).
    *   **Modal de Novos Produtos**: Formulário completo exigindo inserção de código de barras (SKU) e preços para compor o inventário.
    *   **Modal de Movimentação Manual**: Permite que o gerente lance Entradas ou Saídas diretamente pelo computador (com campo de "Motivo"), atualizando os estoques na mesma fração de segundo.
*   **Módulo de Relatórios**:
    *   Tabela de Histórico (Auditoria) que lista a data/hora, tipo (Entrada/Saída), produto, quantidade e quem foi o responsável que autorizou.

## 3. Fase 3: Landing Page Pública (Next.js)
A página de vendas e conversão do sistema AEMEK foi desenvolvida no diretório `/landing-page`.

*   **Design Premium e Foco em Conversão**:
    *   Construída em "Dark Mode" utilizando estéticas modernas como *Glassmorphism* (elementos translúcidos), gradientes de luz pontuais e alto contraste nas chamadas de ação.
*   **Animações e Experiência do Usuário (UX)**:
    *   Integração com a biblioteca **Framer Motion**.
    *   O topo da página (*Hero Section*) conta com elementos de entrada fluidos e texturas modernas.
    *   Os *cards* de "Recursos" aparecem de forma sequenciada e reagem ao passar o mouse (*hover*).
*   **Ponto de Acesso Central**:
    *   O botão de "Login" localizado na barra de navegação pública leva o cliente direto para o Painel Administrativo, unificando os ecossistemas.
